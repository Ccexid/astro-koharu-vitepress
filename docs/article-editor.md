# 文章正文与本地写作（阶段 1＋2）

此次按 2026-10-16 确认的范围加入本地可视化编辑，沿用 Vue 3、TypeScript、Bun 和现有 Cloudflare Worker。尚未加入线上发布、D1、R2、Access 或文章写入接口。

## 入口与工作流

- `/posts/article-style-guide`：新增原创演示文章《让文字有自己的形状》，包含全部首批正文类型，正常参与列表、分类、标签、归档和推荐。
- `/editor`：一份新文章工作区。
- `/editor?post=<文章 slug>`：为对应文章打开独立的本地草稿；阅读页提供编辑入口，页脚提供“本地写作”入口。
- 修改后约 800ms 自动存入 IndexedDB，也可点击“保存草稿”。再次进入同一个工作区或刷新时恢复上次保存。Pinia 只保存当前编辑状态。
- “真实预览”与阅读页使用同一个 `ArticleRenderer.vue`，目录、字数和阅读时间均由正文计算。预览不改动公开文章。
- “文章信息与封面”可以设置 slug、日期、分类、标签、封面及置顶。标签格式为 `名称:slug`，以逗号分隔。
- “JSON 导入”通过正文结构、版本与地址校验后才允许替换工作区，替换前提示备份；“JSON 导出”允许标题、slug、日期、分类等元信息尚未写完，空或无效 slug 使用 `article-draft.json` 文件名。文件上限为 2 MB（UTF-8 字节数）。未完成草稿同样能导入、导出和自动保存；封面若已填写，必须是安全的图片地址。
- 标题、摘要等元信息与正文均在中文组合输入结束后再自动保存；标签在输入时同步到草稿，无需先失焦。切换文章或离开页面会先尝试保存；失败或仍在组合输入时提示可能丢失未保存内容。关闭标签页也有未保存提醒。
- 两个窗口同时编辑同一工作区时，IndexedDB 事务内比较 revision，拒绝过时写入，提示先导出当前内容再载入。清除浏览器站点数据会删除草稿，需自行保留 JSON 备份。
- 存储不可用或记录损坏时显示错误并保留原记录；可以重试，或选择临时编辑并导出备份。临时编辑不自动覆盖原草稿。

这是本地编辑入口，访客可用；**保存不是线上发布**。草稿不跨浏览器、域名、端口或设备同步。无痕窗口的草稿通常随会话结束而清除。

## 内容协议

`ArticleDraft` 包含文章元信息、`contentVersion: 1` 和 Tiptap 风格的 `content: { type: 'doc', content: [...] }`。JSON 是唯一正文源，不存储 HTML 或 Markdown 副本。

`services/article-content.ts` 负责白名单校验、旧 `sections` 转换、标题锚点、目录和统计。`services/posts.ts` 返回带版本号的正文，保留旧字段用于兼容；旧标题 ID 原样保留。新标题通过编辑器生成稳定 ID，重复或不合法的导入锚点在校验时修正。重复文字格式被拒绝，避免渲染不受控的嵌套元素。阅读时间按每分钟 300 个中文字符/其他语言词的粗略计数估计，最少 1 分钟；显式换行参与分词。`postFromDraft` 另行严格校验完整元信息，所以导出的未完成草稿不能直接成为公开文章。

首批支持：

| 内容         | 编辑与阅读行为                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------- |
| H2～H4、段落 | 稳定锚点、多级目录；正文支持左、中、右对齐                                                     |
| 文字格式     | 加粗、斜体、删除线、高亮、行内代码、链接；兼容下划线节点                                       |
| 列表与引用   | 有序、无序、任务、多层列表；Tab/Shift+Tab 或工具栏调整缩进；引用块                             |
| 代码块       | plaintext、JavaScript、TypeScript、JSON、CSS、HTML、Python、Bash；语言选择、语法高亮、复制反馈 |
| 图片         | 稳定 URL、替代文本、说明；阅读/预览失败回退、重试、点击大图、Esc 关闭                          |
| 表格         | 表头开关、增删行列、段落对齐；窄屏横向滚动                                                     |
| 提示块       | 信息、成功、警告、错误四类，可切换和移除                                                       |
| 阅读辅助     | 分割线、摘要、目录、字数与阅读时间                                                             |

阅读器用 Vue 文本节点和白名单元素渲染，不使用 `v-html` 或创建 Tiptap 实例。代码高亮仅注册上述语言。编辑页通过 Vue Router 懒加载，Tiptap/ProseMirror 不进入首页和阅读页的静态依赖。

链接接受 http(s)、站内根路径、锚点、mailto 和 tel；图片只接受 http(s) 或站内根路径。拒绝 JavaScript、data、协议相对路径、控制字符、反斜杠等地址；忽略任意事件、样式等未知属性。正文限制节点数、嵌套深度、单段和总文字量。图片仍可能触发对所填远端地址的普通请求，不包含图片代理或上传能力。

## 将导出文件纳入仓库

现在通过本地发布脚本自动纳入文章目录，不再手动修改 `posts.ts`：

```sh
bun run article:publish "导出的文章.json"
```

脚本校验必填信息、正文与全站 ID/slug，按稳定 ID 新增或更新 JSON，然后执行文章测试、类型检查和生产构建；检查失败恢复原文件。通过后预览、提交并推送 Git，由已连接的 Cloudflare Workers Builds 自动构建部署。完整命令、更新规则、失败恢复与账号侧连接步骤见 [文章发布说明](article-publishing.md)。仅把文件下载到本机不会自动进入访客可读数据。

后续线上发布应另设草稿和发布版本，服务端验证身份、必填项与正文结构，支持恢复旧版本。当前 Worker 继续承担原有 API 转发与静态资源职责。
