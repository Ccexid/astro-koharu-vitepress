## 视觉观察与本项目决策

| 观察项   | 参考站表现                                               | 本模板实现基线                                                                   |
| -------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 首屏     | 樱花影像铺满头图区，站点标题居中，底部以柔和波形连接正文 | 保留全幅春日影像、居中标题与柔和收口；用 Unsplash 远程图片，不复用上游插画或截图 |
| 站点结构 | 顶部导航、作者侧栏、纵向文章卡片                         | 桌面使用顶部导航、作者信息侧栏与文章流；窄屏收起侧栏并改用导航抽屉               |
| 色彩     | 粉色强调色搭配浅色纸面，深色模式偏梅紫                   | 粉白为主，增加叶绿作为第二强调色；深色背景降低饱和度并保留粉色交互提示           |
| 内容卡片 | 图像、分类、日期、标题和摘要组成文章入口                 | 用真实可读的模拟文章、封面替代占位 lorem，提供完整详情、分类与标签链接           |
| 交互     | 主题切换、移动导航与页面导航                             | 保留主题切换和移动导航；暂不实现花瓣动画、音乐播放器等可选效果                   |

## 已知边界

- 本项目是 Vue Router history 模式的客户端 SPA。生产托管需要将未知路径回退到 `index.html`；这只保证客户端路由可打开，不会生成独立文章 HTML。
- 常见配置示例：Netlify 可在 `_redirects` 写 `/* /index.html 200`；Nginx 可在站点的 `location /` 使用 `try_files $uri $uri/ /index.html;`。部署前需在目标托管环境再次验证深层链接刷新；Vite 开发服务器的回退成功不等于任意生产托管自动支持。
- 本阶段使用本地结构化模拟数据，不实现 Markdown 解析、后端 API、身份验证、搜索服务、评论、RSS 或 sitemap。
- 上游的可选音乐、追番、系列、国际化与复杂 Markdown 能力不在本阶段的验收范围内。
