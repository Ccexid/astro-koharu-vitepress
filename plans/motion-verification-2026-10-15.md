# 动效验收记录 · 2026-10-15

参考版本保持 `.reference/v7.7.4`，提交 `edc0cd6466dfa3c7dd1d0052302e0e4565818b28`。没有新增依赖、图片或字体。当前文章卡片样式、滚动追加和双源追番保持原有实现。

## 实现

1. `SiteHero` 首页三层标题按 120/230/340ms 延迟，以 760ms 从 28px 上移并显示。图片元素挂载时未 complete 才监听 load，执行 1800ms 的 1.08 → 1 收束。图像、背景视差、文字视差分开承载 transform；图片 load 监听、动画和媒体查询监听在销毁时清理。
2. 精选分类使用独立 Vue 组件，720ms 翻面和 100ms hover 防误触。显式按钮支持鼠标、键盘和触屏；未显示的一面使用 inert；Escape 收起并回到按钮。减少运动时两面静态顺序显示。复用一次性视口显示逻辑，键盘焦点进入时立即显现，避免等待滚动动画。
3. 页面使用 Vue Transition，普通导航离场 160ms、入场 260ms。支持 View Transitions 时只有点击的文章标题与文章封面标题共享 `article-title`，520ms；等待真实文章封面就绪后拍摄新快照，最多等 1 秒，失败不阻断导航。取消旧动画后再开始主题/路由动画，旧动画完成回调不会清掉新动画状态。减少运动时直接切换。
4. 波浪曲线按周期扩展到可视区域两侧，三层以 12/7/4 秒横向循环，底边保持填充。花瓣有不同尺寸、方向和旋转幅度；封面离屏或文档隐藏时暂停。saveData、deviceMemory ≤ 4GB 或 hardwareConcurrency ≤ 4 时只保留三片花瓣，波浪静止。

页面衔接仅捕获文章标题，整页不进入原生快照层。实测整页快照会阻挡快速连续的鼠标导航；移除后在共享标题动画仍运行时可点击“关于”跳走，也可点击主题按钮开始主题过渡。

## 验证边界

- `complete=true` 的静止分支由生命周期测试覆盖；浏览器已捕获实际 load 收束，但未把 HTTP 缓存命中与网络首次下载作独立性能实验。
- 移动端为浏览器宽度和粗指针模拟，尚未在真实手机上验证触摸手感；低配也未在真实低性能设备上测帧率。
- 减少运动使用本地验证页模拟，没有修改用户 OS 设置；没有宣称跨浏览器实机兼容或真实 DevTools 10% 回放完成。
- 不支持滚动时间线的浏览器通过 `@supports` 保持静态；本轮未在缺少该能力的真实浏览器中运行。
